# Sprint 15 Objectives: Host Dashboard

## Theme
Build out the complete Host tournament management experience — from pre-tournament setup through live match orchestration.

## Primary Goals

1. **Host Command Centre** — Redesign and harden the existing `tournaments/[id]` dashboard into a fully featured, state-driven command centre.
2. **Registration & Ingestion Flow** — Finalize the registration phase toggle, magic link sharing, and CSV bulk ingestion with proper feedback.
3. **Pools & Seeding Workspace** — Complete the pools workspace with serpentine auto-seeding, category tabs, drag-and-drop reordering, and draft-save capability.
4. **Match Dispatcher** — Build the Order of Play view: filterable match list (by category, status, stage), court assignment, and match state transitions.
5. **Sandbox Visualization** — Keep the `/sandbox/host` preview in sync with every real feature as it ships.

## Out of Scope This Sprint
- Referee control panel (carried from sprint 14 notes — next priority after host is complete)
- Knockout bracket generation (depends on pool stage completion)
- Player-facing pool publication view
