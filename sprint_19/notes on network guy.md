# Notes on Network Guy (The IT Command Center)

The Network Admin ensures the digital and physical infrastructure of the tournament remains online. They operate entirely behind the scenes but have the most technical view of the system.

## Suggested Non-Negotiables for the Network Admin
1. **Device Fleet Monitoring**: Must have real-time visibility into the battery life, signal strength (Wi-Fi/Cellular), and online status of every Umpire tablet and Marshall radio.
2. **Remote Troubleshooting**: Must be able to send remote commands to field devices (e.g., "Force Refresh Cache", "Remote Reboot", "Reconnect WebSocket").
3. **Database Health & Edge Server Pinging**: Needs visibility into database read/write latency. If the server goes to sleep, they need a "Coldstart / Wake" button.
4. **Latency Tracking**: Needs to know if a specific court is experiencing high latency (which delays the Broadcaster scorebug and frustrates fans).

## Aesthetic
- Defaults to a highly technical "Terminal / Hacker" aesthetic (dark mode, monospace fonts, green/red status indicators).
- Includes a toggle to switch back to the "Standard/Clean" Tennis Suite UI.
